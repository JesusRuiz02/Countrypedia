A modern App created with "Jetpack Compose" and Clean Architecture (MVVM, HILT, MODULE AND REPOSITORIES) this project shows my Curriculum Vitae and a little countrypedia using RESCOUNTRIES API

Features:
-State Management: Using Shimmer Effect to provide the maximum USER EXPERIENCE
-Cache: Caching country data obtained by RESTCOUNTRIES API to optimize API calls
-Animations: Animations integrated to get a better UX for the user
-Error Handling: Graceful handling of network failures and empty states.

Tech Stack:
-Language: Kotlin
-Framework: Jetpack Compose Material 3
-Libraries to manage Asynchronous Stuff: Retrofit
-Asynchronous loader image: COIL
-Architecture: MVVM with repostory pattern
-Dependency Injection: Hilt
